# cliferay mysql create

Create and start the MySQL container, with the current database already created

## Usage

```bash
cliferay mysql create [VERSION]
```

## Examples

```bash
cliferay mysql create
```

```bash
cliferay mysql create 8.4
```

## Arguments

#### *VERSION*

The tag of the mysql Docker image to use

| Attributes      | &nbsp;
|-----------------|-------------
| Default Value:  | 8
